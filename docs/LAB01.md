[TB + CHMURA] Gdzie znaleźć aktualizacje projektu ATINS Komis?

Drodzy Studenci zespołów Technologie Backendowe (TB) oraz CHMURA,

Wszystkie aktualizacje projektu laboratoryjnego ATINS Komis znajdziecie w naszym wspólnym repozytorium GitHub:

https://github.com/ATINS-Labs/atins-komis-template

## 1. Gałąź główna — main

https://github.com/ATINS-Labs/atins-komis-template/tree/main

Gałąź main zawiera oficjalną wersję szablonu projektu przeznaczoną do pracy laboratoryjnej.

To od niej rozpoczynajcie nowe ćwiczenia, o ile prowadzący nie wskaże inaczej.

## 2. Gdzie będą publikowane aktualizacje?

Nowe materiały laboratoryjne są przygotowywane i testowane przez prowadzącego na osobnych gałęziach rozwojowych.

Po zakończeniu weryfikacji zatwierdzone aktualizacje będą udostępniane w gałęzi głównej **`main`**:

https://github.com/ATINS-Labs/atins-komis-template/tree/main

Informacje o nowych wersjach, zmianach w zadaniach i dodatkowych materiałach będą publikowane w **Discussions → Announcements**.

**Uwaga:** nie korzystajcie z niezatwierdzonych gałęzi rozwojowych, chyba że prowadzący wyraźnie wskaże je do wykonania konkretnego ćwiczenia.

## 3. Gdzie sprawdzać informacje o nowych wersjach?

Discussions → Announcements — komunikaty dotyczące laboratoriów i aktualizacji.

Pull Requests — proponowane zmiany oczekujące na zatwierdzenie.

Releases — opublikowane, oznaczone wersje materiałów, gdy zostaną przygotowane.

README.md — instrukcje pracy z projektem.

## 4. Ważna informacja o własnych repozytoriach

Jeśli utworzyliście wcześniej własne repozytorium przez Use this template, zmiany w szablonie nie pojawią się w nim automatycznie.

Nie wykonujcie samodzielnie git reset --hard, git push --force ani nadpisywania lokalnych plików w celu aktualizacji projektu.

Instrukcje bezpiecznej synchronizacji będziemy przekazywać osobno.

## 5. Jak otrzymywać powiadomienia?

Na stronie repozytorium wybierzcie Watch → Custom i włączcie powiadomienia o Discussions oraz Releases, jeżeli te opcje są dostępne.

Ogłoszenia dotyczące konkretnej grupy będą oznaczone [TB] lub [CHMURA]. Informacje wspólne otrzymają oznaczenie [TB + CHMURA].

Proszę regularnie sprawdzać ogłoszenia przed kolejnymi laboratoriami.
